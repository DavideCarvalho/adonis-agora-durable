A `tenant` pod sends a token with every request it makes to the control plane. The control plane checks the token and decides which tenant the pod is; whatever the request claims about itself is ignored. Two settings in `config/durable.ts` carry this:

- `verifyTenant`, on the control plane: turns a token into `{ tenant, capabilities }`, or rejects it.
- `tenant.token`, on the tenant pod: the token to send.

Durable does not care where the token comes from. Pick the setup that matches what your app already runs:

| You have | Control plane | Tenant pod |
| --- | --- | --- |
| [`@adonisjs/auth`](#with-adonisjsauth-access-tokens) | Verify access tokens with your tokens provider | A static access token |
| [authkit](#with-authkit) | `authkitTenantVerifier()` | `authkitTenantToken(...)` |
| [Any OIDC provider](#with-any-oidc-provider) (Keycloak, Auth0, Entra ID...) | Verify JWTs against the provider's keys | `client_credentials`, refreshed before expiry |
| [Nothing](#with-a-shared-secret-hmac) | `hmacTenantVerifier(secret)` | `signTenantToken(partition, secret)` |

<Callout type="warn">
Without `verifyTenant`, the control plane trusts the tenant a request names. Any process that can reach the broker can then read, signal, cancel and start runs as any tenant. Run without a verifier only when each tenant's broker access is already isolated.
</Callout>

## The contracts

Both settings accept a function, or a class you write in its own file. The classes implement one of two interfaces exported by `@adonis-agora/durable`.

### `TenantVerifierContract`

```ts
import type { TenantVerifierContract, TenantVerifierInput, VerifiedTenant } from '@adonis-agora/durable'

export default class MyTenantVerifier implements TenantVerifierContract {
  async verify({ token }: TenantVerifierInput): Promise<VerifiedTenant | null> {
    // ...
  }
}
```

#### `verify(input)`

Called on the control plane for every request a tenant pod sends.

- `input.token` is the token the pod sent. It is `undefined` when the pod sends none.
- `input.tenant` is what the request claims. Never use it to decide the tenant.
- Return `{ tenant, capabilities? }` to accept. `tenant` is the partition the pod acts as: its runs are created in, and confined to, that namespace.
- Return `null` to reject. The pod's call fails with a `RunGatewayError` whose `code` is `unauthorized`.
- Throw when you cannot decide (your database or the identity provider is down). The pod's call fails with the error message, and the next request calls `verify` again.

The control plane calls `verify` for every message, so cache results that cost a database or network round trip.

### `TenantCredentialsContract`

```ts
import type { TenantCredentialsContract } from '@adonis-agora/durable'

export default class MyTenantCredentials implements TenantCredentialsContract {
  async token(): Promise<string> {
    // ...
  }
}
```

#### `token()`

Called on the tenant pod before every request it sends.

- Return the token. It is sent unchanged.
- Cache it and fetch a new one before it expires: `token()` runs once per request.
- Throw (or return an empty string) when no token is available. That request fails with the error, and the next request calls `token()` again.

### Registering them

`verifyTenant` takes the same forms as a console's `authorize`:

```ts title="config/durable.ts (control plane)"
// 1. A function
verifyTenant: hmacTenantVerifier(env.get('DURABLE_TENANT_SECRET')),

// 2. A class. The container builds it once, so @inject() works
verifyTenant: MyTenantVerifier,

// 3. A lazy import of a module whose default export is the class (imported once)
verifyTenant: () => import('#tenants/my_tenant_verifier'),

// 4. An object that has a verify() method
verifyTenant: new OidcTenantVerifier({ ... }),
```

`tenant.token` takes a string, a function, or the same class, lazy import and object forms with a `token()` method:

```ts title="config/durable.ts (tenant)"
tenant: { token: env.get('DURABLE_TENANT_TOKEN') },
tenant: { token: async () => vault.read('durable/token') },
tenant: { token: () => import('#tenants/my_tenant_credentials') },
tenant: { token: new ClientCredentials({ ... }) },
```

## With `@adonisjs/auth` access tokens

Use this when the app already has [`@adonisjs/auth`](https://docs.adonisjs.com/guides/authentication/access-tokens-guard) and a database. Each tenant pod is a row of a model, and gets an access token whose abilities are its capabilities. No identity provider and no shared secret.

### The model

```ts title="app/models/service_tenant.ts"
import { DbAccessTokensProvider } from '@adonisjs/auth/access_tokens'
import { BaseModel, column } from '@adonisjs/lucid/orm'

export default class ServiceTenant extends BaseModel {
  @column({ isPrimary: true })
  declare id: number

  /** The partition this tenant process acts as. */
  @column()
  declare partition: string

  static accessTokens = DbAccessTokensProvider.forModel(ServiceTenant, {
    prefix: 'dtt_',
    type: 'durable_tenant',
  })
}
```

Create a `service_tenants` table with an `id` and a `partition` column. The tokens live in the `auth_access_tokens` table that `@adonisjs/auth` already uses; the `type` keeps them apart from your users' tokens.

### Mint a token

```ts title="commands/durable_tenant_token.ts"
import { args, BaseCommand, flags } from '@adonisjs/core/ace'
import type { CommandOptions } from '@adonisjs/core/types/ace'
import ServiceTenant from '#models/service_tenant'

export default class DurableTenantToken extends BaseCommand {
  static commandName = 'durable:tenant:token'
  static description = 'Create an access token for a durable tenant pod'
  static options: CommandOptions = { startApp: true }

  @args.string({ description: 'The partition the pod acts as' })
  declare partition: string

  @flags.array({ description: 'Capabilities granted to the pod' })
  declare capability: string[]

  @flags.string({ description: 'Token lifetime, e.g. 90 days' })
  declare expiresIn: string

  async run() {
    const tenant = await ServiceTenant.firstOrCreate({ partition: this.partition })
    const token = await ServiceTenant.accessTokens.create(
      tenant,
      this.capability?.length ? this.capability : ['*'],
      this.expiresIn ? { expiresIn: this.expiresIn } : {}
    )
    this.logger.success(`Token for ${this.partition} (shown once):`)
    this.logger.log(token.value!.release())
  }
}
```

```sh
node ace durable:tenant:token acme-corp --capability=gpu --expires-in="90 days"
```

Revoke a pod with `ServiceTenant.accessTokens.delete(tenant, tokenId)`, or delete the row.

### The control plane

```ts title="app/tenants/access_token_tenant_verifier.ts"
import { createHash } from 'node:crypto'
import { Secret } from '@adonisjs/core/helpers'
import type { TenantVerifierContract, TenantVerifierInput, VerifiedTenant } from '@adonis-agora/durable'
import ServiceTenant from '#models/service_tenant'

/**
 * Verifies the access tokens of `ServiceTenant` rows. The control plane sees every message a tenant
 * sends, so each result, accepted or rejected, is reused for `cacheTtlMs` instead of querying the
 * database every time. A deleted token keeps working for at most that long; an expiring token is
 * never accepted past its expiry.
 */
export default class AccessTokenTenantVerifier implements TenantVerifierContract {
  #cacheTtlMs: number
  #maxEntries: number
  #cache = new Map<string, { result: VerifiedTenant | null; until: number }>()

  constructor(options: { cacheTtlMs?: number; maxEntries?: number } = {}) {
    this.#cacheTtlMs = options.cacheTtlMs ?? 30_000
    this.#maxEntries = options.maxEntries ?? 10_000
  }

  async verify({ token }: TenantVerifierInput): Promise<VerifiedTenant | null> {
    if (!token) return null
    // Keyed by a hash, so the cache never holds a usable token.
    const key = createHash('sha256').update(token).digest('base64url')
    const hit = this.#cache.get(key)
    if (hit && hit.until > Date.now()) return hit.result

    // A database error is thrown, not cached: the request fails and the next one asks again.
    const accessToken = await ServiceTenant.accessTokens.verify(new Secret(token))
    const owner = accessToken ? await ServiceTenant.find(accessToken.tokenableId) : null
    const result =
      accessToken && owner ? { tenant: owner.partition, capabilities: accessToken.abilities } : null

    let until = Date.now() + this.#cacheTtlMs
    if (accessToken?.expiresAt) until = Math.min(until, accessToken.expiresAt.getTime())
    this.#cache.delete(key)
    this.#cache.set(key, { result, until })
    if (this.#cache.size > this.#maxEntries) {
      const oldest = this.#cache.keys().next().value
      if (oldest !== undefined) this.#cache.delete(oldest)
    }
    return result
  }
}
```

```ts title="config/durable.ts (control plane)"
export default defineConfig({
  topology: 'control-plane',
  // ...
  verifyTenant: () => import('#tenants/access_token_tenant_verifier'),
})
```

## With authkit

If the control plane runs [authkit](/docs/authkit), there is nothing to write. Create a service-tenant client in the authkit console (or with `node ace authkit:clients:create`), give it a partition and its capabilities, and use authkit's verifier and token source:

```ts title="config/durable.ts (control plane, the authkit app)"
import { authkitTenantVerifier } from '@adonis-agora/authkit-server'

verifyTenant: authkitTenantVerifier(),
```

```ts title="config/durable.ts (tenant)"
import { authkitTenantToken } from '@adonis-agora/authkit-client'

tenant: {
  token: authkitTenantToken({
    issuer: env.get('AUTHKIT_ISSUER'),
    clientId: env.get('DURABLE_TENANT_CLIENT_ID'),
    clientSecret: env.get('DURABLE_TENANT_CLIENT_SECRET'),
  }),
},
```

Rotating a secret, disabling a client and the server-side config are on authkit's [Service tenants](/docs/authkit/service-tenants) page.

## With any OIDC provider

Each tenant pod is an OAuth client of your identity provider. It gets a short-lived JWT access token with the `client_credentials` grant and sends it; the control plane checks the token's signature against the provider's published keys, without calling the provider for each message. These two classes use [`jose`](https://github.com/panva/jose) (`npm i jose`).

Configure each client on the provider to issue JWT access tokens that carry:

- `aud`: the control plane's resource identifier, e.g. `urn:agora:durable`, requested with `resource` (RFC 8707);
- `partition`: the tenant the client acts as;
- `capabilities` (optional): a string array.

The provider's discovery document (`{issuer}/.well-known/openid-configuration`) lists the `jwks_uri` and `token_endpoint` used below.

### The control plane

```ts title="app/tenants/oidc_tenant_verifier.ts"
import { createRemoteJWKSet, errors, jwtVerify } from 'jose'
import type { TenantVerifierContract, TenantVerifierInput, VerifiedTenant } from '@adonis-agora/durable'

export interface OidcTenantVerifierOptions {
  /** The IdP's issuer; must equal the token's `iss`. */
  issuer: string
  /** The control plane's resource identifier; must be in the token's `aud`. */
  audience: string
  /** The IdP's key set (`jwks_uri` in `{issuer}/.well-known/openid-configuration`). */
  jwksUri: string
  /** Claim naming the partition. Default `partition`. */
  partitionClaim?: string
  /** Claim listing the capabilities. Default `capabilities`. */
  capabilitiesClaim?: string
}

/**
 * Verifies JWT access tokens (RFC 9068) issued by any OIDC provider, locally: the signing keys are
 * fetched once and cached by `jose`, which fetches them again when a token names a key it has not
 * seen (key rotation). Only asymmetric algorithms are accepted, never `none` or `HS*`.
 */
export class OidcTenantVerifier implements TenantVerifierContract {
  #options: OidcTenantVerifierOptions
  #jwks: ReturnType<typeof createRemoteJWKSet>

  constructor(options: OidcTenantVerifierOptions) {
    this.#options = options
    this.#jwks = createRemoteJWKSet(new URL(options.jwksUri))
  }

  async verify({ token }: TenantVerifierInput): Promise<VerifiedTenant | null> {
    if (!token) return null
    try {
      const { payload } = await jwtVerify(token, this.#jwks, {
        issuer: this.#options.issuer,
        audience: this.#options.audience,
        algorithms: ['RS256', 'PS256', 'ES256', 'EdDSA'],
        requiredClaims: ['exp'],
        clockTolerance: 30,
      })
      const tenant = payload[this.#options.partitionClaim ?? 'partition']
      if (typeof tenant !== 'string' || tenant === '') return null
      const capabilities = payload[this.#options.capabilitiesClaim ?? 'capabilities']
      return {
        tenant,
        capabilities: Array.isArray(capabilities)
          ? capabilities.filter((c): c is string => typeof c === 'string')
          : undefined,
      }
    } catch (error) {
      // A bad token is a rejection. A key set that cannot be fetched is an error the tenant sees.
      if (error instanceof errors.JOSEError && !(error instanceof errors.JWKSTimeout)) return null
      throw error
    }
  }
}
```

```ts title="config/durable.ts (control plane)"
import { OidcTenantVerifier } from '#tenants/oidc_tenant_verifier'

export default defineConfig({
  topology: 'control-plane',
  // ...
  verifyTenant: new OidcTenantVerifier({
    issuer: env.get('OIDC_ISSUER'),
    audience: 'urn:agora:durable',
    jwksUri: env.get('OIDC_JWKS_URI'),
  }),
})
```

### The tenant pod

```ts title="app/tenants/client_credentials.ts"
import type { TenantCredentialsContract } from '@adonis-agora/durable'

export interface ClientCredentialsOptions {
  /** The IdP's token endpoint (`token_endpoint` in its discovery document). */
  tokenEndpoint: string
  clientId: string
  clientSecret: string
  /** The control plane's resource identifier, sent as `resource` (RFC 8707). */
  resource: string
  scope?: string
  /** Fetch a new token this many seconds before the current one expires. Default 60. */
  refreshSkewSec?: number
}

/**
 * Gets the tenant's access token with the OAuth `client_credentials` grant and keeps it fresh. Calls
 * made while a request to the IdP is in flight share it. When the IdP fails, the current token is
 * kept while it is still valid and the IdP is not asked again for 5 seconds.
 */
export class ClientCredentials implements TenantCredentialsContract {
  #options: ClientCredentialsOptions
  #current: { token: string; refreshAt: number; expiresAt: number } | undefined
  #inflight: Promise<string> | undefined
  #retryAt = 0

  constructor(options: ClientCredentialsOptions) {
    this.#options = options
  }

  async token(): Promise<string> {
    const now = Date.now()
    const current = this.#current
    if (current && now < current.refreshAt) return current.token
    const stillValid = current && now < current.expiresAt ? current.token : undefined
    if (stillValid && now < this.#retryAt) return stillValid

    this.#inflight ??= this.#fetch().finally(() => {
      this.#inflight = undefined
    })
    try {
      return await this.#inflight
    } catch (error) {
      this.#retryAt = Date.now() + 5_000
      if (stillValid) return stillValid
      throw error
    }
  }

  async #fetch(): Promise<string> {
    const { clientId, clientSecret, resource, scope } = this.#options
    const body = new URLSearchParams({ grant_type: 'client_credentials', resource })
    if (scope) body.set('scope', scope)
    const basic = Buffer.from(
      `${encodeURIComponent(clientId)}:${encodeURIComponent(clientSecret)}`
    ).toString('base64')
    const response = await fetch(this.#options.tokenEndpoint, {
      method: 'POST',
      headers: {
        authorization: `Basic ${basic}`,
        'content-type': 'application/x-www-form-urlencoded',
        accept: 'application/json',
      },
      body,
      signal: AbortSignal.timeout(10_000),
    })
    // Never put the response body in the error: it is not ours to log.
    if (!response.ok) throw new Error(`token endpoint answered HTTP ${response.status}`)
    const json = (await response.json()) as { access_token?: unknown; expires_in?: unknown }
    if (typeof json.access_token !== 'string') throw new Error('token response has no access_token')

    const lifetimeMs = (typeof json.expires_in === 'number' ? json.expires_in : 300) * 1000
    const skewMs = (this.#options.refreshSkewSec ?? 60) * 1000
    const now = Date.now()
    this.#current = {
      token: json.access_token,
      expiresAt: now + lifetimeMs,
      // A token shorter-lived than the skew is refreshed at half its life instead.
      refreshAt: now + (skewMs < lifetimeMs ? lifetimeMs - skewMs : lifetimeMs / 2),
    }
    this.#retryAt = 0
    return json.access_token
  }
}
```

```ts title="config/durable.ts (tenant)"

  topology: 'tenant',
  partition: 'acme-corp',
  // ...

    token: new ClientCredentials({
      tokenEndpoint: env.get('OIDC_TOKEN_ENDPOINT'),
      clientId: env.get('DURABLE_TENANT_CLIENT_ID'),
      clientSecret: env.get('DURABLE_TENANT_CLIENT_SECRET'),

  },

```

## With a shared secret (HMAC)

With no user store and no identity provider, sign each pod's partition with a secret only the control plane and you know:

```ts
import { hmacTenantVerifier, signTenantToken } from '@adonis-agora/durable'

// Mint the token a pod presents (once, e.g. in an ace command); ttlMs makes it expire:
const token = signTenantToken('acme-corp', env.get('DURABLE_TENANT_SECRET'), {
  ttlMs: 24 * 60 * 60 * 1000,
})

// Control plane. A list of secrets lets you rotate: verify with [next, current], re-mint, drop current.
verifyTenant: hmacTenantVerifier([env.get('DURABLE_TENANT_SECRET_NEXT'), env.get('DURABLE_TENANT_SECRET')]),

// Tenant pod:
tenant: { token: env.get('DURABLE_TENANT_TOKEN') },
```

`hmacTenantVerifier(secret, capabilities)` grants the same `capabilities` to every pod; the token carries none of its own.

## Wire compatibility

Whatever produced it, the token travels as a plain string in the `tenant` field of each request, the same field [aviary](/docs/durable/cluster/interop) Python and NestJS processes use. An aviary control plane that does not verify tokens reads the whole string as the tenant name and finds no runs for it, so a misrouted pod is refused rather than let in.
